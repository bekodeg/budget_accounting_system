# 12. Переводы между счетами

## 12.1. Семантика

TRANSFER перемещает деньги между двумя счетами одного бюджета.

Он не является ни доходом, ни расходом бюджета.

```text
source balance      -= amount
destination balance += amount
income summary      += 0
expense summary     += 0
net cash flow       += 0
```

## 12.2. Инварианты

До записи проверяется:

- source account существует и активен;
- destination account существует и активен;
- оба счета принадлежат активному бюджету;
- source и destination различаются;
- сумма строго положительная;
- валюты счетов совпадают.

Межвалютные переводы в MVP запрещены. Для FX потребуется отдельная модель курса,
двух денежных legs и правил округления.

## 12.3. Хранение

TRANSFER хранится одной transaction row:

- `type = TRANSFER`;
- `account_id` — источник;
- `destination_account_id` — получатель;
- `category_id = NULL`;
- `amount_minor` — положительная величина;
- `currency` — общая валюта двух счетов.

## 12.4. UI

В общей форме операции доступны:

- Расход;
- Доход;
- Перевод.

Для перевода поле категории заменяется выбором счета назначения.

## 12.5. Отчеты

`ReportDao` агрегирует income/expense только по соответствующим типам,
поэтому TRANSFER не попадает в cash-flow summary.

Баланс счетов учитывает transfer симметрично.

## 12.6. Тестирование

Покрыты:

- успешное создание transfer;
- запрет перевода на тот же счет;
- запрет межвалютного transfer;
- widget flow создания;
- balance source/destination;
- period summary, игнорирующий transfer.

Полный Flutter gate выполняется на stage.
